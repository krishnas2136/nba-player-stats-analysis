
**NBA Players Stats Analysis**

**Overview**

This repository contains an exploratory data analysis (EDA) of historical NBA player statistics.


**Dataset**

Source: Kaggle - NBA Players Stats


**Features & Analyses**

**Top Scorers Analysis:** Bar plots highlighting top performers.
**Age Dynamics:** Scatter plots analyzing age vs. performance metrics.
**Positional Comparison:** Box plots measuring statistical variance across player positions.
**Historical Trends:** Line plots showcasing scoring evolution over decades.


**Libraries Used**

pandas
numpy
matplotlib
seaborn


**Setup & Execution** 

Open [Google Colab](https://colab.research.google.com/). 
Click on `File` > `Open notebook` > Select `GitHub` tab. 
Paste your repository link and open `NBA_Players_Stats_Analysis.ipynb`. 
Upload the `Seasons_Stats.csv` dataset in the Colab files section and run all cells.
